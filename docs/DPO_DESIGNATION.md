# 数据保护官（DPO）指定书

> 依据《中华人民共和国个人信息保护法》第52条，处理个人信息达到国家网信部门规定数量的个人信息处理者，应当指定个人信息保护负责人。

## 1. 指定信息

| 项目 | 内容 |
|------|------|
| **职务名称** | 数据保护官 (Data Protection Officer) |
| **所属部门** | 合规与安全部 |
| **汇报对象** | 公司主要负责人 / CEO |
| **指定日期** | 2026-05-23 |
| **联系方式** | dpo@zhiyu.local |

## 2. 职责

1. **合规监督** — 监督个人信息处理活动是否符合 PIPL 及相关法律法规的要求
2. **保护影响评估** — 组织个人信息保护影响评估（PIA），对高风险处理活动提出改进建议
3. **安全事件响应** — 发生个人信息安全事件时，组织应急响应，并在 72h 内向主管部门报告
4. **数据主体权利** — 受理并处理个人信息查阅、复制、更正、删除、携带、撤回同意等请求
5. **培训与审计** — 定期组织个人信息保护培训，开展内部合规审计
6. **监管对接** — 作为与网信办及监管部门沟通的联络人

## 3. 独立性保障

- DPO 独立行使职权，不受业务部门干扰
- DPO 有权直接向公司主要负责人汇报
- 公司不得因 DPO 依法履行职责而降低其薪酬或解除劳动关系
- DPO 所需资源（人力、技术、经费）由公司保障

## 4. 记录要求

- DPO 履职记录保存期限：不少于 3 年
- 处理个人信息活动的记录保存期限：不少于 3 年
- 个人信息保护影响评估报告保存期限：不少于 3 年

## 5. 相关法律

- 《中华人民共和国个人信息保护法》（2021.11.01 施行）
- 《中华人民共和国数据安全法》（2021.09.01 施行）
- 《中华人民共和国网络安全法》（2017.06.01 施行）
- 《数据出境安全评估办法》（2022.09.01 施行）
